# Scaleup Consulting website redesign preview

A design preview of the scaleupconsulting.com.au redesign, exported from Magic Patterns. This is not the live site, and it is marked `noindex` so search engines skip it.

Some prices and review details are placeholders generated with the design. Check them against the live feature menu before reusing any copy.

```
npm install
npm run dev      # local preview
npm run build    # production build in dist/
```
